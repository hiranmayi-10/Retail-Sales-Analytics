# 📊 Retail Sales Analytics using Python

## 📌 Project Overview

This project analyzes retail sales data using Python to identify sales trends, profitable product categories, customer segments, and regional performance. The project includes data cleaning, visualization, and business recommendations based on the analysis.

## 🎯 Objectives

- Analyze retail sales performance
- Identify top-performing product categories
- Compare regional profitability
- Analyze customer segments
- Study the relationship between discounts and profit

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## 📂 Dataset

- Sample Superstore Dataset

## 📈 Project Workflow

1. Data Loading
2. Data Exploration
3. Data Cleaning
4. Exploratory Data Analysis
5. Data Visualization
6. Business Insights
7. Recommendations

## 📊 Visualizations

- Sales by Category
- Sales Distribution (Pie Chart)
- Profit by Region
- Discount vs Profit
- Sales by Segment
- Quantity by Category
- Top 10 Sub-Categories

## 🔍 Key Findings

- Technology generated the highest sales.
- Consumer customers contributed the highest sales.
- Regional profitability varied significantly.
- Higher discounts often reduced profitability.

## 💡 Business Recommendations

- Increase investment in high-performing categories.
- Reduce excessive discounts to improve profit.
- Improve marketing strategies in low-performing regions.
- Maintain inventory for high-demand products.
